# VidPocket Store Assets

Prepared assets for Chrome Web Store submission.

## Icon

- `icon/vidpocket-icon-128.png`

The icon is 128x128 PNG. The same icon is also included in the extension package under `assets/icons/icon128.png`.

## Screenshots

- `screenshots/vidpocket-world-cup-1280x800.png`
- `screenshots/vidpocket-nba-1280x800.png`

Both screenshots are 1280x800 PNG files.

## Promotional Images

- `promotional/vidpocket-small-promo-440x280.png`
- `promotional/vidpocket-marquee-1400x560.png`

The 440x280 image is the required small promotional tile. The 1400x560 image is optional.

## Source Images

- `screenshots/source-world-cup.png`
- `screenshots/source-nba.png`
- `promotional/vidpocket-promo-source.png`

These are retained so the store assets can be regenerated later.
