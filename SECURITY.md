# Security Policy

## Supported Versions

The default branch is the only supported development line unless release branches are created later.

## Reporting a Vulnerability

Please open a GitHub security advisory or contact the maintainer privately if you find a vulnerability that could expose local files, execute unexpected commands, or leak browsing data.

Please include:

- affected version or commit
- operating system and Chrome version
- reproduction steps
- expected and actual behavior

## Non-Security Reports

Requests to bypass DRM, platform protections, login walls, or encrypted media are not security issues and are outside the project scope.
