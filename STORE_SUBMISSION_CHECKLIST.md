# Chrome Web Store Submission Checklist

Use this checklist before uploading VidPocket.

## Files Prepared In This Repository

- `STORE_LISTING.md`: English and Chinese store copy.
- `PRIVACY.md`: bilingual privacy policy.
- `REVIEW_NOTES.md`: reviewer test notes.
- `store-assets/icon/vidpocket-icon-128.png`: 128x128 extension icon reference.
- `store-assets/screenshots/vidpocket-world-cup-1280x800.png`: screenshot.
- `store-assets/screenshots/vidpocket-nba-1280x800.png`: screenshot.
- `store-assets/promotional/vidpocket-small-promo-440x280.png`: required small promo tile.
- `store-assets/promotional/vidpocket-marquee-1400x560.png`: optional marquee promo tile.
- `dist/vidpocket-0.4.3.zip`: upload package generated by `npm run package:store`.

## Dashboard Fields

- Name: `VidPocket`
- Category: `Productivity`
- Language: English, with Chinese (Simplified) localization if enabled.
- Homepage URL: `https://github.com/BryceYuuu/vidpocket-page-video-downloader`
- Support URL: `https://github.com/BryceYuuu/vidpocket-page-video-downloader/issues`
- Privacy policy URL: `https://github.com/BryceYuuu/vidpocket-page-video-downloader/blob/main/PRIVACY.md`

## Upload Steps

1. Run tests:

```sh
npm test
```

2. Generate the Chrome Web Store ZIP:

```sh
npm run package:store
```

3. Open the Chrome Web Store Developer Dashboard.
4. Create a new item or upload a new package.
5. Upload:

```text
dist/vidpocket-0.4.3.zip
```

6. Fill Store Listing using `STORE_LISTING.md`.
7. Fill Privacy using `PRIVACY.md` and the permission explanations in `STORE_LISTING.md`.
8. Paste `REVIEW_NOTES.md` into review instructions.
9. Upload the image assets from `store-assets/`.
10. Set distribution, visibility, and submit for review.

## Policy-Sensitive Wording

Use:

- "directly accessible webpage media"
- "unencrypted HLS streams"
- "does not bypass DRM"
- "use only when you have the right to save the media"

Avoid:

- "download any video"
- "works on every site"
- "YouTube downloader"
- "bypass protected video"
- keyword blocks or repetitive keyword stuffing

## Remaining Manual Items

- Register or sign in to the Chrome Web Store developer account.
- Confirm the developer/publisher display name.
- Choose target countries and visibility.
- Decide whether to keep Chinese localization enabled in the dashboard.
- Confirm that the privacy policy URL is public after pushing `PRIVACY.md` to GitHub.
